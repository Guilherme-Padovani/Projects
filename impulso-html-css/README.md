# Impulso — Landing Page Responsiva

**Projeto de portfólio | HTML5 • CSS3**

Página de apresentação para uma plataforma **fictícia** de estudos. O objetivo é demonstrar estrutura HTML semântica, design visual, acessibilidade básica e adaptação a telas de diferentes tamanhos.


![Prévia da interface](preview.png)

## O que esta página demonstra

- Menu de navegação com âncoras que funcionam.
- Seção inicial (hero) com uma ilustração criada usando **CSS**, sem imagens externas.
- Cartões de benefícios e três trilhas ilustrativas.
- Seção de perguntas com o elemento HTML nativo `<details>` (sem JavaScript).
- Grid, Flexbox, media queries e estilos para celular.
- Estrutura semântica com `header`, `main`, `nav`, `section`, `article` e `footer`.

## Como executar

Basta abrir `index.html` em qualquer navegador moderno. Não há dependências nem servidor.

## O que é fictício

A marca, os cursos e as trilhas são exemplos. Não há plataforma real, formulário de inscrição nem serviços pagos. Os links levam a seções desta própria página.

## Como apresentar numa entrevista

Explique por que separou HTML e CSS, como usa Grid nos cartões, por que existem regras `@media` e o que muda no layout quando a tela fica menor.

Antes de usar no currículo, leia o `GUIA_DE_ESTUDO.md` e faça uma modificação com suas próprias mãos.
