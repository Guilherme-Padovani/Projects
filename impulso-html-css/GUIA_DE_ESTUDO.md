# Entendendo a Landing Page

1. Abra `index.html`: `header` é o cabeçalho, `nav` agrupa a navegação, `main` contém o conteúdo principal e `footer` fecha a página.
2. Encontre o link `href="#trilhas"`. Ele aponta para a seção com `id="trilhas"`.
3. Abra `style.css`: `.container` controla a largura do conteúdo.
4. `display: grid` cria colunas nos cartões; `display: flex` organiza itens como os links do menu.
5. `@media(max-width:760px)` muda a disposição dos elementos em telas pequenas.
6. A seção de perguntas usa `details` e `summary`: abrir e fechar funciona com HTML, sem JavaScript.
7. A ilustração principal é montada com blocos HTML e formas feitas com CSS.

## Pequenos desafios
