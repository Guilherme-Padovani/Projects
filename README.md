# Portfólio — Engenharia de Software

Projetos desenvolvidos durante minha formação em **Engenharia de Software na FIAP**, com foco em evolução prática de lógica de programação, desenvolvimento Back-end, APIs e banco de dados.

## Projetos em destaque

### 1. Sistema de Gerenciamento de Estoque
**Python • SQLite • SQL**

Aplicação de terminal para cadastro, consulta, edição e exclusão de produtos, com controle de entrada e saída de estoque e persistência em banco de dados.

➡️ [Ver projeto](./sistema-estoque-python-sqlite)

---

### 2. API REST de Gerenciamento de Tarefas
**Python • Flask • SQLite • REST • JSON • HTTP**

API Back-end com CRUD completo, filtros, validação de dados, métodos HTTP e respostas com códigos de status adequados.

➡️ [Ver projeto](./api-tarefas-flask-sqlite)

---

### 3. Sistema Web de Gerenciamento de Chamados
**Python • Flask • SQLite • HTML • CSS**

Aplicação web completa para gerenciamento de chamados de suporte, integrando Front-end, Back-end e banco de dados, com pesquisa, filtros, prioridades e controle de status.

➡️ [Ver projeto](./sistema-chamados-flask-sqlite)
