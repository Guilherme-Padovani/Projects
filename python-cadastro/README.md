# Sistema de Cadastro e Login — Python

Projeto simples desenvolvido para praticar lógica de programação em Python.

## O que o projeto faz
- Cadastra novos usuários (nome, e-mail e senha)
- Valida e-mails duplicados e senhas curtas
- Permite login com e-mail e senha
- Lista todos os usuários cadastrados
- Menu interativo no terminal

## Conceitos aplicados
- Estruturas condicionais (`if` / `else`)
- Laços de repetição (`while`, `for`)
- Listas e dicionários
- Funções
- `match/case`

## Como executar
```bash
python cadastro.py
```
